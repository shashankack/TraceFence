# TraceFence

**NullTrace** · Mystara hackathon · Cybersecurity  

Source-aware security gateway for AI agents: *Know what your AI reads. Control what it does.*  

QR/URL → offline synthetic page inspect → agent proposes tools → server policy ALLOW / DENY / APPROVAL → source-linked audit.
